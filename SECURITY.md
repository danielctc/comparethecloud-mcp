# Security policy

## Reporting a vulnerability

Report it through the [contact page](https://www.comparethecloud.net/contact) with "MCP security" in the subject, a description of the issue, the steps to reproduce it, and the endpoint or tool affected.

Please do not open a public issue for an unfixed vulnerability.

## Scope

In scope:

- the MCP Worker at `mcp.comparethecloud.net`, including the `/mcp` endpoint, the `/register` key flow, authentication, and rate limiting;
- the code in this repository.

Out of scope: the `www.comparethecloud.net` website and vendor-supplied directory content. Report content errors through the [contact page](https://www.comparethecloud.net/contact).

## Response

We aim to acknowledge and triage a report within 5 working days. We do not run a bounty programme.

Test only against your own key and requests. Do not access other people's data or degrade the service for others.
